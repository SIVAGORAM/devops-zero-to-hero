# Python Day 28: Python + Docker Automation

Welcome to **Day 28**! 
A DevOps engineer doesn't type `docker run` or `docker stop` manually in production. They use automation scripts to build, deploy, monitor, and clean up containers seamlessly.

There are **two ways** to automate Docker using Python:
1. The `subprocess` module (Executing raw Docker CLI commands).
2. The **Docker SDK for Python** (Communicating directly with the Docker Engine API).

---

## 1. Method 1: The `subprocess` Module
For quick, dirty scripts, you can just execute standard Docker CLI commands from Python.

```python
import subprocess

try:
    # Always use capture_output=True, text=True, and check=True
    result = subprocess.run(["docker", "ps", "-a"], capture_output=True, text=True, check=True)
    print("Docker Containers:\n", result.stdout)
except subprocess.CalledProcessError as e:
    print(f"Docker command failed: {e.stderr}")
```

---

## 2. Method 2: The Docker SDK (The Senior DevOps Standard)
The Docker SDK is a massive upgrade over `subprocess`. Instead of parsing messy text outputs from the CLI, it returns structured Python Objects!

**Installation:**
```bash
pip install docker
```

**Connection:**
```python
import docker

# Connects to the local Docker Engine automatically
client = docker.from_env()
```

---

## 3. Container Lifecycle Automation
With the SDK, container management is incredibly clean and object-oriented.

```python
import docker
from docker.errors import NotFound

client = docker.from_env()

# 1. Starting a container in the background (detach=True)
container = client.containers.run("nginx:latest", name="my-nginx", detach=True)
print(f"Booted Container: {container.short_id}")

# 2. Safely finding and stopping a container
try:
    existing_container = client.containers.get("my-nginx")
    print(f"Found {existing_container.name}. Current Status: {existing_container.status}")
    
    existing_container.stop()
    existing_container.remove()
    print("Container destroyed.")
except NotFound:
    print("Container does not exist.")
```

## 4. Image Automation (Build & Pull)
You can automate the CI/CD build process entirely in Python.

```python
import docker

client = docker.from_env()

# Pulling an image
print("Pulling redis:alpine...")
client.images.pull("redis:alpine")

# Building a Dockerfile in the current directory
image, build_logs = client.images.build(path=".", tag="my-python-app:1.0")
print("Build Successful!")
```

## 5. Advanced DevOps: Live Troubleshooting (`exec_run`)
A massive part of DevOps is debugging a broken container. Instead of SSHing into the host and running `docker exec`, you can execute commands *inside* the running container directly from Python!

```python
import docker

client = docker.from_env()
container = client.containers.get("my-nginx")

# Equivalent to: docker exec my-nginx cat /etc/nginx/nginx.conf
exit_code, output = container.exec_run("cat /etc/nginx/nginx.conf")

if exit_code == 0:
    print("NGINX Config:\n", output.decode("utf-8"))
else:
    print("Command failed!")
```

---

## 6. Advanced DevOps: Streaming Logs
If you deploy a new container, you often want to watch the logs to ensure it boots correctly. Instead of pulling all logs at once, you can **stream** them in real-time just like `docker logs -f`!

```python
import docker

client = docker.from_env()
container = client.containers.get("my-nginx")

print("Streaming logs in real-time. Press Ctrl+C to stop.")
# stream=True yields log lines as they are generated by the container
for line in container.logs(stream=True):
    print(line.decode("utf-8").strip())
```

## 7. DevOps Monitoring: The "Revive" Script
A very common DevOps automation is scanning for crashed containers and restarting them.

```python
import docker

client = docker.from_env()

# all=True ensures we get stopped/crashed containers, not just running ones
for container in client.containers.list(all=True):
    if container.status == "exited":
        print(f"ALERT: {container.name} is down! Attempting restart...")
        container.restart()
        print(f"{container.name} revived.")
```
